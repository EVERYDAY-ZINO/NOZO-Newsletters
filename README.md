# NOZO Newsletters

한국전력기술 노동조합 소식지 편집 저장소입니다. 호(issue)별로 폴더를 나눠 관리합니다.

## 구조

```
2026-03-04/
  index.html     # 2026년 3·4월호 편집본 (브라우저로 열어서 확인)
  photos/        # 본문에 쓰인 활동 사진
```

새 호를 편집할 때는 `YYYY-MM` 형식으로 폴더를 하나 더 만들어서 같은 패턴을 따르면 됩니다.

## 2026년 3·4월호 — 편집 노트

원본 `.hwp` 초안(1~4월 활동 소식)을 다음과 같이 정리/교정했습니다.

- 1~2월: 6건의 활동 기사를 날짜순으로 재배열하고 사진을 매칭
- 3~4월: 원본의 대외/대내 활동 목록을 그대로 정리
- 오탈자 교정: "나웠습닏.k" → "나눴습니다.", "공우하고" → "공유하고", "주속적으로" → "지속적으로", "시긴이" → "시간이", "서택" → "사택", 문장 사이 누락된 띄어쓰기 등
- ⚠️ **확인 필요**: 울진 현장 사택 관련 문단의 "하버팰리채"는 실제 사택 명칭으로 추정되어 "하버팰리스"로 임시 교정했습니다. 정확한 명칭을 확인 후 알려주시면 반영하겠습니다.
